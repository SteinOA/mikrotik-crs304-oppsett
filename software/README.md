# Programvare

Modell: CRS304-4XG-IN. Arkitektur: ARM64.

Brukt under gjenopprettingen:

- Netinstall 7.25 for Windows 64-bit: https://download.mikrotik.com/routeros/7.25/netinstall64-7.25.zip
- RouterOS 7.25 ARM64: https://download.mikrotik.com/routeros/7.25/routeros-7.25-arm64.npk
- WinBox 4.4 var allerede installert: https://mikrotik.com/download/winbox

Produktside og oppdaterte nedlastinger: https://mikrotik.com/product/crs304_4xg_in

Last ned Netinstall, RouterOS og WinBox fra de offisielle lenkene ovenfor. Den offentlige veiledningen videreformidler ikke leverandørens binærfiler. [MikroTiks lisensvilkår](https://mikrotik.com/software/legal) gjelder for programvaren. Historiske SHA-256-kontrollsummer for filene brukt i den dokumenterte økten ligger i [SHA256SUMS.txt](SHA256SUMS.txt); de er ikke en garanti for at en senere versjon har samme kontrollsum.

7.25 er versjonen vi brukte, ikke et løfte om at den er nyeste eller riktig versjon ved neste installasjon. Kontroller leverandørens anbefalinger og modellstøtte først.
